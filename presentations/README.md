# Presentations Directory

Place your presentation slides PDF files in this folder.

Expected file names according to the research portfolio configuration:
- `proposal.pdf` : Project Proposal Presentation Slides
- `progress-1.pdf` : Progress Presentation 1 Slides
- `progress-2.pdf` : Progress Presentation 2 Slides
- `final.pdf` : Final Presentation Slides
- `viva.pdf` : Viva Presentation Slides

When you drop your actual PDF files here, they can be immediately opened and downloaded from the website.
